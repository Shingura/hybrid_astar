# Hybrid A*：让 A* 学会开车

本文是 `src/hybrid_astar.cpp` 的阅读指南，假设你已经熟悉 `docs/astar.md` 里的栅格 A*。

## 与栅格 A* 的对照

骨架完全不变：open list（优先队列）、松弛（best_cost）、parent 回溯、过期副本跳过。换掉的只有三个"零件"：

| 零件 | 栅格 A* | Hybrid A* |
|---|---|---|
| 状态 | `(row, col)` | `(x, y, θ)`，连续位置 + 车头朝向 |
| 邻居 | 上下左右瞬移 | 采样方向盘转角，运动学仿真一小段弧 |
| 启发 | 曼哈顿距离 | max(栅格 Dijkstra 距离, 欧氏距离) |

## 1. 运动学模型（自行车模型）

把车简化成前后两个轮子：给定方向盘转角 δ，车绕一个圆心打转，半径 R = L / tan(δ)（L 是轴距）。

```
x'     = v · cos(θ)
y'     = v · sin(θ)
theta' = v / L · tan(δ)
```

`simulate()` 把每段弧切成 5 小步数值积分。最大转角由最小转弯半径决定：δmax = atan(L / R)。

**为什么这很重要**：车不能横移、不能原地掉头（非完整约束），栅格 A* 的路径车开不了。运动学仿真保证每个扩展出来的状态都是车真实能开到的。

## 2. 扩展邻居

双重循环：`steering_samples` 个方向盘转角 × {前进, 倒车}。每个组合仿真 `step_size` 弧长，沿途采样检查碰撞。代价：

```
g = 父节点 g + 弧长 × (倒车 ? 倒车惩罚 : 1) + 换向惩罚 × |δ - 父节点 δ|
```

惩罚项的意义：倒车和猛打方向都是"不舒服"的驾驶行为，惩罚让搜索偏好平稳前进的路径。

## 3. 离散化：连续的运动，离散的账本

连续状态几乎永远不会重复，没法直接查 best_cost。做法：把 (x, y) 按格子切、θ 切成 `heading_bins` 档，三维桶 `(行, 列, 朝向档)` 作为记账单位；同桶内只保留 g 最小的节点（松弛）。路径点本身保留连续精度。

## 4. 启发函数

- `grid_distances_from_goal()`：从终点在栅格上跑一次 Dijkstra，得到每个格子**绕开障碍**的真实距离——"遵守障碍、忽略车辆约束"
- 欧氏距离——"忽略障碍、遵守……什么都不遵守"

两者取 max，仍然不高估，且比任何一个单独都更紧（搜索扩展更少节点）。

## 5. 解析扩展

每扩展 20 个节点，尝试用纯追踪（pure pursuit）从当前状态直接开到终点：每小步朝终点方向按比例修正方向盘，无碰撞到达就提前收工。这让路径末尾是光滑的"一把进"，而不是锯齿。

**这是 Reeds-Shepp 曲线的简化替代**。教科书做法是用 RS 曲线（前进/倒车 + 圆弧 + 直线组成的 48 种最短路径模式）直连终点，并把 RS 距离也加入启发函数取 max。想进阶可以查 "Reeds-Shepp curves"，替换 `try_analytic_expansion()` 即可，接口不用变。

## 6. 运行与验证

```bash
cmake -B build && cmake --build build
./build/demo          # 演示：终端打印 + 图片存到 output/*.ppm
./build/run_tests     # 或 ctest --test-dir build
```

测试覆盖：栅格 A* 最优性（27 格）、路径连续性、不穿墙；hybrid A* 起终点正确、不穿墙、相邻点曲率不超车辆极限。

## 7. 教学简化（与工程实现的差距）

- 车辆按**质点**碰撞检测；工程上按车半径膨胀障碍物，或按车体轮廓多圆检测
- 解析扩展用纯追踪替代 Reeds-Shepp
- 地图是 0/1 障碍；实车常用距离场（distance field）让车离墙有安全余量
